# copiloto-academico
Copiloto Acadêmico
Você decide. O Copiloto sugere.

Sobre o projeto
O Copiloto Acadêmico é uma plataforma web desenvolvida para auxiliar estudantes universitários na organização de atividades acadêmicas.

Funcionalidades
Gestão de atividades
Planejamento de estudos
Calendário
Notificações
Materiais acadêmicos
Acessibilidade
Controle de esforço acadêmico
Tecnologias
HTML5
CSS3
JavaScript
Node.js
